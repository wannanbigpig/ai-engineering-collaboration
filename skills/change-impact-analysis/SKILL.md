# 变更影响分析

修改前追踪受影响路径、数据流和风险，先分析后实施。

项目有 `.aitasks/` 时，用本包的[只读查询脚本](scripts/query_aitasks.py)取摘要：`python3 -B "<skill-dir>/scripts/query_aitasks.py" --project-root "<project-root>" context --query "模块 符号 错误码"`。`<skill-dir>` 取当前 Skill 的实际安装目录。按返回 ID 用 `get-record --kind lesson --id …`（todo 用 `--kind todo`）读必要正文。结论核对当前调用链与契约。

**无 Python 3.10+ 的降级。** 命令找不到或版本不够时，按以下两步查询，整个任务最多取三条命中标题。标题查询须先静默检查 Markdown 围栏，只有检查返回 1 才继续。发现围栏或读取失败时跳过该文件的标题和状态，标为未验证。关键词留在标题锚定式内。

```bash
if rg --no-config -q -- '^[[:blank:]]*(`{3,}|~{3,})' .aitasks/lessons.md; then
  printf '%s\n' '记录文件含围栏，标题和状态未验证。' >&2
elif [ "$?" -eq 1 ]; then
  rg --no-config -ni -m 3 -- '^##[[:blank:]]+.*(关键词一|关键词二)' .aitasks/lessons.md
fi
```

第一步有标题命中时，才逐条提取状态。将两个 `6` 换为标题行号减一，仅输出紧邻同类注释里的 `status`。

```bash
sed -nE -e '6s/^[ ]{0,3}<!-- aitasks:lesson( [^[:space:]<>]+)* status=(active|retired|superseded)( [^[:space:]<>]+)* -->[[:space:]]*$/status=\2/p' -e '6q' .aitasks/lessons.md
```

查 todo 时使用 `.aitasks/todo.md`、`aitasks:todo` 和状态 `active|completed|cancelled`。缺少对应状态或归属不明时标为未验证。两步结束即停止读记录文件。禁止宽泛关键词搜索、上下文行、区间读取或编写临时解析器。经验正文及适用性保留未验证，依据当前代码与契约取证。若无法隔离标题和状态输出，记为未验证，跳过经验查询。

## 追踪清单

只检查与当前变化相关且尚未明确的路径；复用已有调用链与风格基线，不重复调查已核实部分。按变更类型选择：

- **入口与调用链**：页面/CLI/交互入口、API/命令/事件、Controller/Service/Model 定义及调用方。
- **复用检查**：新增函数、模块、接口或兼容分支前，在受影响范围内检索已有实现、扩展点和项目惯例；说明选择复用、扩展或有意保持重复的理由，不因名称不同就断定行为不同，也不强制跨业务边界抽象。
- **风格与界面基线**：按受影响部分核对同类实现和共享设施，复用已有基线。后端关注相关分层、校验、错误或事务约定；前端关注相关组件、状态、API 或样式约定。没有明确 UI 设计时，以目标模块的同类页面、共享布局、组件和设计令牌为参照；只在布局、交互或状态行为受影响时检查对应响应式及加载/空/错误状态，文案修改核对目标文本和溢出等直接影响即可。找不到可靠参照或现有模式冲突时说明依据，不以个人偏好补造规范。
- **数据与异步**：读写、校验、转换、Job/事件/队列/定时任务、重试和幂等。
- **边界与契约**：权限、数据范围、租户隔离、输入输出、序列化、错误码、缓存一致性。
- **基础设施与协作**：迁移、索引、跨仓库 reader/writer、测试、部署和回滚。

## 方法与输出

- 从入口沿受影响路径追踪定义、调用方和数据流；已知目标和局部关系直接检索、读取，尚未明确的结构或跨模块关系在已接入 CodeGraph 时优先用图谱定位。不可用或结果不足时用自身可用的检索工具补足。
- 打开并核对实际实现，不根据符号名或单一调用点猜测。
- 输出受影响文件/模块、风险等级、证据和需要额外验证的路径。

## 边界

本阶段只分析、不修改文件，无法确认的路径标记未验证。输出结论和剩余缺口后返回调用方；已有实施授权的任务可继续实施，不因完成分析重复询问。独立的只读分析在交付结论后停止，无需为标记未验证加载其他 Skill。
