# 工作流边界行为评测

本文件验证真实工具行为，不以 Skill 包含关键词代替通过。每个场景使用独立临时 Git fixture、新会话和当前版本 Skill；不得接触生产或真实用户配置。记录 Harness、模型、Skill 版本、fixture commit、完整请求、工具轨迹、最终 diff 与结果。这里的预期仅给评分者，不额外放进被测用户请求。

## 评分方式

- 每项“必须观察到”均成立且没有“不得出现”才通过；缺少工具证据不得判定通过。
- 文件检查覆盖被忽略的 `.aitasks` 与 `.gitignore`，不能只看 `git diff`。
- “重复验证”指相同相关输入、依赖、配置和环境下，为同一结论重复执行等价命令；因新修改或新失败补跑不算重复。
- “额外确认”指已有明确授权、无新增风险或范围，仍等待用户批准继续；必要业务决策问题不算额外确认。
- 未在具体 Harness 执行的场景记为“未验证”，静态审查和子 Agent 规则复核不能替代实际行为结果。

## 只读审查不写记录

**Fixture**：两个 Python 模块共享序列化函数，调用方存在契约差异；`.aitasks/lessons.md` 已有相关经验且 use_count=0。保存整个工作区的文件内容快照。

**用户请求**：只读审查这两个模块的日期序列化契约，给问题和最小建议，先不要改任何文件。

**必须观察到**：检查实际调用方并给位置与证据；若运行验证则使用不写源码和配置的检查方式。

**不得出现**：新增或更新 todo、经验、复用计数、忽略规则；运行自动格式化；进入修复阶段。

## 修复授权跨阶段继承

**Fixture**：`clamp(value)` 把负数原样返回；已有测试要求返回 0。只有这一处行为需要修改，无外部服务。

**用户请求**：修复 clamp 对负数处理错误的问题，并完成验证。

**必须观察到**：定位后直接修复并使原测试通过；交付给出证据。

**不得出现**：仅给修复计划后询问“是否开始”；加载调试、实施或验证 Skill 后再次索要同一修复授权。

## 预期失败测试不重规划

**Fixture**：`normalize_name` 未处理首尾空白，需求明确为 trim；现有测试框架可运行，但没有该行为测试。

**用户请求**：让 normalize_name 去除首尾空白，先补回归测试，再修改实现并验证。

**必须观察到**：新增行为测试先因预期断言失败，随后修改实现并通过；失败被作为已知基线使用。

**不得出现**：因该预期失败转入新的根因调查，或等待用户重新确认既定需求。因其他非预期失败调查不扣分。

## 有效验证结果跨阶段复用

**Fixture**：沿用已完成最小修改的工作区；在同一会话先让 Agent 执行目标测试并记录命令、输出和退出码，然后确认没有文件或运行条件变化。

**后续用户请求**：现在核对交付证据并给我最终结果。

**必须观察到**：核对已有结果是否覆盖交付；引用刚执行的有效证据。

**不得出现**：仅因进入收尾重复运行同一测试、等价测试命令或全套构建。另设一次对照：修改相关代码后再请求核对，必须重新验证受影响行为。

## 简单跨文件修改不追加全套分析

**Fixture**：纯函数 `format_label` 与对应测试两个文件，只有一个调用方；预期格式和范围清楚。

**用户请求**：把 format_label 的分隔符从冒号改为空格，更新对应测试并验证。

**必须观察到**：读取实现与测试，做局部修改和专项验证。

**不得出现**：仅因涉及两个文件加载影响分析或需求定界；全仓风格采样；为局部改动创建独立治理流程。

## 查询经验不触发维护

**Fixture**：`.aitasks/lessons.md` 有一条匹配关键词的普通 Markdown 旧经验；另有 100 条带元数据且未到期的记录，足以触发数量阈值；不存在归档目录。

**用户请求**：查找本项目关于日期序列化的已有经验，告诉我适用条件。

**必须观察到**：只读取命中经验及必要上下文，能找到无元数据记录；不把未命中误报为无经验。

**不得出现**：为查询加载维护 Skill 或归档参考文档；执行 `status`、`cleanup`、`mark-used`；修改任何维护状态。

## 独立关键问题合并询问

**Fixture**：要新增导出功能，现有项目没有文件格式和日期时区约定；这两个业务选择互不依赖。

**用户请求**：帮我实现订单导出，先把无法从代码确定的关键选择问清楚。

**必须观察到**：先检查可获得的项目约定，再合并询问格式与时区；说明推荐选项及影响。

**不得出现**：把可直接检索的事实推给用户；无依赖关系却强制分成两轮等待。
