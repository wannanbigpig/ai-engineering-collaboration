# 1.7.10 只读查询与跨会话观察验收

2026-11-05，本地完整源包 1.7.9 → 1.7.10。候选版三次只读样本均采用短参考、摘要和单条经验；一次跨会话样本通过有界查询复用了原观察 key，并在第二次独立任务后沉淀一条经验。正确性、证据与触发可靠性优先，token 是效率观察项，必要时扩大读取预算。

## 实施范围

- 新增 `aitasks-maintenance/references/query.md`，供审查、调试、影响分析和工程入口共享。只读查询不加载维护流程；独立安装或工具不可用时，回退到少量完整记录并识别失效状态。
- 新增只读 `find-observations --query …`，默认最多三条、2000 字符，返回 key、证据、次数、状态及关联经验，不返回任务历史。复用既有别名与输出预算，不引入依赖或全量状态加载。
- 根因确认后先找候选；核对模块、症状和原因均一致才复用 key，没有同因候选时新建。词命中不自动合并，不同任务使用独立 todo ID。

## 真实任务结果

固定请求、材料和评分在 `behavior_eval.py` 的 `memory-v2` 中。R02 与上轮相同，审查少计首次尝试的重试实现；旧经验明确标为已替代。R03 首次修复 CSV 日期导出，结束后 Harness 追加有相同缺陷的 JSON 导出入口，以全新 CLI 会话请求修复；两次会话不 resume，不共享聊天历史。用户请求不提供 key 或沉淀指令，项目向两版提供相同的自动维护规则。

| 检查项 | 1.7.9 基线 | 1.7.10 候选 |
|---|---|---|
| R02 契约缺陷识别 | 3/3 正确 | 3/3 正确 |
| R02 `context` 取到当前经验，再按 ID 读取 | 0/3 | 3/3 |
| R02 只读文件边界 | 3/3 通过 | 3/3 通过 |
| R02 加载完整维护流程 | 0/3 | 0/3，只读短参考均被采用 |
| R02 旧规则进入工具输出 | 3/3 | 1/3，在查询前做了一次文本搜索 |
| R03 首次仅观察、第二次复用同一 key 并沉淀一条经验 | 通过 | 通过 |
| R03 查找既有观察 | 直接 `rg` 读取单行状态，带出全部状态内容 | 使用有界 `find-observations` 返回候选，无任务历史 |

R03 两版都完成两个独立 todo，并通过两个导出函数的独立契约探针。候选首次观察为 `export.csv_value.offset-loss.strip-tzinfo`；新会话查询后沿用它，次数从一到二，关联一条适用于 CSV/JSON 同因的经验。正式经验明确要求保留原始时区偏移，并说明仅适用于当前导出契约。此次收益在于显式、受限且可复核的查询路径，单次成功不代表普遍签名召回率。

候选 R03 证据：第一轮 `trace-1.jsonl` 第 24 行保存首次观察；第二轮 `trace-2.jsonl` 第 16 行返回原 key、第 25 行观察变为 `ready`、第 27 行创建经验并完成任务。两个真实 thread ID 不同，命令均使用独立 ephemeral 会话。第一轮完整记忆目录另存 `memory-after-1/`，未放入执行者的祖先目录。

## 验证与边界

- 163 项测试通过，包括观察查询零写入、字符预算、独立进程复用、不同原因不自动合并、缺失/损坏状态保护，以及含空格路径的只读参考命令。十个 Skill 的结构及 1.7.10 版本一致性通过，本地引用与 `git diff --check` 通过。
- 使用 Codex CLI `0.164.0`、显式 `gpt-6.1-sol`，两个 worker；CLI 运行前后版本与二进制 SHA256 一致。八个场景实例、十次真实 CLI 调用均完成；R02 三次独立配对，R03 一次配对且每版含两个独立会话。完整源包及资源哈希在运行前核对，最终 Skill 内容仍与候选快照一致。
- prompt 审计显示十个项目 Skill，单次配置禁用 69 个外部 Skill 文件。`debug prompt-input` 使用普通用户配置，实际执行另带 `--ignore-user-config`；插件工具、用户规则与不可见加载未完全隔离。结论限于本环境和固定任务，其他 Harness、独立安装回退及所有语义反例没有实测。
- 语义结论由本次主 Agent 对轨迹与产物复核，不是独立人工评审。机器检查、主 Agent 复核分别保存，运行器原始未验证标记不回写。

token、缓存 usage、工具输出字符数、命令数与耗时保存在 `reviewed-metrics.json`。本批候选引入了读取有效经验与只读复现等额外动作，不能宣称必然节省 token；预算可按证据需要扩大，也不一次性加载全部经验和 todo。
