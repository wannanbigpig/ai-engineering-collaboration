# 1.7.13 工具修复与观察评测

2026-11-06，修复已复现的三个工具缺陷，保留历史 M02 并新增当前观察规则的评测。源码版本 1.7.13；本轮未提交、推送、发布或替换用户安装。

## 三个修复

| 问题 | 实现 | 回归证据 |
| --- | --- | --- |
| 旧经验缺字段时插入围栏破坏记录边界 | 已有和缺失字段共用多行渲染 | 修复前缺字段子例失败；修复后 LF/CRLF 均完整读回围栏、保留笔记和后续记录，`truncated=false` 与正文一致 |
| 首次复制失败留下半成品，重试被定制保护拒绝 | 初装与升级共用同父目录暂存；完整复制后发布，失败清理暂存 | 复制和发布失败后可重试，保留定制冲突与升级恢复；实际 Python 3.9 安装器回归通过 |
| 安装副本非法 UTF-8 导致 JSON stdout 为空 | 版本为 `null`，保留原始内容摘要和差异状态，返回 `diagnostics` | 修复前真实 CLI 输出解码 traceback；修复后 stdout 为完整 JSON、退出 1、原文件不变，文本模式也能看到诊断 |

修复针对已证实路径，没有用修改截断标记掩盖解析问题，也没有把损坏副本当成可覆盖的用户定制。

## 新版评测

历史 `maintenance-v1/M02` 保留原定义和评分，不回写旧结果。它要求第一轮全部文件不变，不能验收首次观察落盘。新增 `maintenance-v2`：

- M06：两个独立分析任务面对同因问题，首次只观察，第二次复用签名并关联一条经验。
- M07：相同的日期偏移症状分别来自导出器移除时区和上游解析截断，核对不同原因不会合并计数或提前沉淀。
- M08：只安装 `code-review`，缺少可选维护工具，检查定向文本回退和全部文件只读。

M06/M07 使用两个新 CLI 会话，不 resume；任务明确允许观察/经验写入，使用不同分析任务 ID，不为维护本身创建 todo。有限探针检查持久化 schema、签名、记录关联、会话身份及字节/权限边界；真实根因与经验质量仍需逐例语义复核。明确只读时不允许观察写入。

## 批次与比较

新增锁定批次身份，分别核对两版源包、运行器及评分模块、CLI 二进制、模型与可见配置。执行者从批次私有冻结副本安装；M08 的单装 profile 同时用于复制、预声明和来源核验。不同条件不能继续追加到同一批次，历史目录可汇总但不能冒充锁定批次。

汇总按批次、场景、重复次数与 split 配对，显式保留未创建、未完成、运行器错误和失败成员；无技能对照单列。只有正确性、授权、验证声明和环境均可信的配对才比较命令数、秒数和 usage。必要的只读/独立会话证据缺失仍阻止比较；不先排除低效样本，缺指标保留 `null`。

批次指纹只证明记录下来的条件一致，不证明所有隐式用户规则、插件工具和 provider 已隔离；指标也不能直接换算为账单或普遍节省。

## 真实任务结果

本轮按预声明运行 M06/M07/M08，新旧版各一次，共 6 个实例、10 次 CLI 调用全部完成，运行器退出 0。显式模型参数为 `gpt-6.1-sol`，Codex CLI 0.164.0，两 worker，单次调用超时 180 秒。原始结果保留，语义复核另存为注明身份的 Agent `review.json`。

| 场景 | 两版的实际结果 | 结论边界 |
| --- | --- | --- |
| M06 同因 | 两版都实际使用两个独立会话和任务 ID，复用一个 key、次数从 1 到 2，生成一条有契约/原因/范围的经验；未改代码 | 有限记录探针及正确性/授权/验证声明复核通过；不因一次成功推断稳定复用率 |
| M07 异因 | 两版都区分导出时清除 `tzinfo` 与上游截去正偏移，保留两个不同 key 各一次观察，无正式经验/todo | 未只凭症状合并；具体建议及验证范围与轨迹一致 |
| M08 单装回退 | 两版都仅安装并读取本地审查 Skill，使用文本检索、正确指出少计首次尝试，全部文件保持只读，未虚构测试或工具成功 | 基线的上下文检索带出失效正文及无关记录，流程维度失败；候选返回更少命中，但没有证明对更大经验库的状态过滤算法 |

六例的任务正确性、授权与验证真实性均通过 Agent 复核；M08 基线另有上述流程失败。所有实例的环境有效性保留 `unverified`：批次和源包已锁定，CLI/运行器摘要及最终候选内容核对一致，但隐式规则、工具与实际 provider 的完整隔离仍未证明。复核者声明参与相关切片，属于非盲 Agent 复核，非独立人工验收。

最终综合结果为 1 例 `fail`、5 例 `unverified`；无待复核或无效复核文件，三个配对均不满足成本比较资格。综合结果与任务正确性逐维结果分别保留。

本轮成对摘要因此不输出可用的成本优劣比较；单对样本也不能证明稳定节省。候选命令较少等现象仅作为轨迹线索，不据此宣称三个工具修复提升了这些任务的模型能力。新口径保留了真实流程失败，没有为了让报告全绿而扩大读取许可或改写历史结果。
