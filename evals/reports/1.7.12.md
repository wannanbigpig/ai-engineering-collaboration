## 测试方法是否正确

现有工具回归和真实 CLI 对照值得保留。需要纠正的是结论的范围：单测通过证明的是程序在已测输入下满足契约，不能证明模型会选择 Skill、遵守指令或提高任务质量。静态关键词断言只能防止历史文字被误删，不应继续增加它们来代替行为验收。

当前 212 项测试中，安装器 45、维护工具 48、记忆流程 33、评测器 57、打包 6、仓库校验 11、可执行文档示例 3；另有 9 项历史文字/场景静态契约。评测器的 57 项测试验证评分和运行逻辑，不是 57 次真实模型任务。

| 层级 | 本项目的合适做法 | 不能据此声称 |
| --- | --- | --- |
| 结构与分发 | 官方格式、版本、自身资源、安装冲突、确定性产物 | 模型理解或自然触发正确 |
| 工具行为 | 真实临时文件、幂等、权限、失败恢复、独立预期和反例 | Skill 内容有效 |
| 选择行为 | 自然请求及相近负例，显式调用另测 | 指定 Skill 成功等于自动选择成功 |
| 任务效果 | 相同环境的旧版/候选/适用的无技能对照；检查产物及执行轨迹 | 一次成功等于稳定提升；模型自述等于验证证据 |

工具改动运行相关回归，CI 运行完整自动检查；正文或 description 变化才定向运行受影响的真实场景。先定评价标准，再冻结候选和保留集。判断顺序为正确性、授权、验证真实性、流程成本；只在正确完成的样本间比较成本。视觉质量需要观察真实页面，语义判断注明是 Agent 复核还是人工评审。

## 真实模型试验

固定 Codex CLI 0.164.0、`gpt-6.1-sol` 和任务材料，共 16 次调用。两版基于真实工作区快照，包含未跟踪源文件；自然选择另设无本地技能对照。预声明与原始结果分别保存，失败不覆盖。以下是开发抽样，不是全仓行为验收。

| 场景 | 样本 | 已观察到的结果 |
| --- | --- | --- |
| S01 函数解释、S03 配置只读审查 | 旧版/候选/无技能各一次，共 6 次 | 任务正确、只读边界和验证声明均通过逐例 Agent 复核；没有显示候选净收益 |
| R02 失效经验与重试契约审查 | 旧版/候选各三次，共 6 次 | 两版均 3/3 正确，均实际使用 `context` 和 `get-record`，均保持只读 |
| F01 后台表单、F02 图书馆页面 | 旧版/候选各一次，共 4 次 | 四次执行与有限契约探针通过；原 CLI 环境未完成浏览器验证，补充观察单列 |

R02 流程仍有问题：旧版 1/3、候选 2/3 通过提前文本搜索把失效条目的内容或元数据带入工具输出；其中错误旧规则正文进入输出两版各 1/3。三个相关样本的流程维度判失败，其余没有因此判失败。最终答复都识别了当前正确契约，但这不消除无关读取问题；当前证据不足以声称新版改善了该行为。

S01/S03 的可见命令数没有形成候选优势。两组评测的环境有效性均保留 `unverified`：标准位置的外部 Skill 已按单次配置禁用，但隐式用户规则、工具和全部上下文隔离未完全证明。自动读取判定只支持严格的绝对路径单条读取，不能把相对路径/复合命令未命中当成未加载；具体输出另由 Agent 复核。

语义复核由负责其他切片或评测器的 Agent 完成，身份记录在每个 `review.json` 中；它们不是独立人工或盲评。本轮未使用 S07/S08 保留集调优，也未重新运行 R03；R03 本次修复的是会话身份证据缺失时的评分规则，由反例测试验证。

前端原始轨迹中，四次 Chrome 进程都以 134 退出；没有虚构浏览器通过。F01 两版另外将环境解释为禁止本地端口监听，原轨迹没有对应启动/绑定命令或错误，因此这部分验证声明仍缺证据。后补宿主服务可启动不能证明被测 CLI 环境也可启动。
