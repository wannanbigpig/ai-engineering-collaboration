# 1.7.9 记忆召回与真实任务试验

2026-11-05，本地源码 1.7.8 → 1.7.9。结论：有界查询的归档召回和失效过滤已改善，真实修复任务采用了单条经验；只读审查仍绕过查询工具。没有总输入 token 下降的证据，不能宣称自动记忆或节省比例已达标。

## 改动与固定场景

- 少量本地中英文同义组，按概念去重；活动经验弱匹配时合并归档排名，保持默认各三条摘要和总计 2000 字符预算。
- `active`、`retired`、`superseded` 生命周期；默认查询排除失效条目，按 ID 保留审计和替代指向，状态变化可恢复。旧记录默认有效，归档不等于失效。
- 归档经验可按 ID、任务 ID 幂等计数；同日维护追加与记录更新一起预检。

固定用户请求、fixture 和预声明标准在 `behavior_eval.py` 的 `MEMORY_SCENARIOS`、`memory_fixture` 中。R01 修复 `timeout=0` 被默认值覆盖，具体经验在归档、活动区只有泛化经验；R02 只读审查额外重试次数，旧经验标为已替代。两组均有三十条无关经验。用户请求不提供工具命令、经验 ID 或评分项。

完整源包配对使用 Codex CLI `0.164.0`、显式 `gpt-6.1-sol`，模型沿用同环境 runtime header 的默认值；两个版本按相同参数独立运行。CLI 运行前后版本与二进制 SHA256 一致。每组只做一轮、每轮两版，属于问题发现试验，没有统计代表性。

外部 Skill 禁用改为具体 `SKILL.md` 文件路径，包含常规目录及插件缓存。prompt 审计可见十个项目 Skill，禁用清单含 69 个文件。`debug prompt-input` 使用普通用户配置，实际执行另带 `--ignore-user-config`；工具 schemas、用户规则与不可见加载尚未完全隔离，不能据此宣称跨宿主触发已验证。
